Start with <a href={href("docs/getting-started/")}>Getting started</a>, then follow the <a href={href("docs/detailed-workflow/")}>step reference</a> through planning, implementation, verification and review. The sidebar covers configuration, risk policy, GitHub settings and recovery.

The workflow runs on your machine. As shipped, Claude implements and Codex reviews, so install both providers. You approve planning and merge pull requests; no script merges for you. Under the shipped policy every feature is reviewed. A project can explicitly allow Low features to skip review; their merge then needs the owner.

## Find a command or setting
