## Start a project

<CodeBlock label="Terminal commands" code={`# a new repository from the template
gh repo create my-project --template taspinar/agentic-coding-template --private --clone
cd my-project
./scripts/doctor.sh
# plan once: requirements, architecture, roadmap; you approve
./scripts/start-planning.sh --description idea.md
# then each feature, from Issue to pull request
./scripts/create-feature-issue.sh F01
./scripts/run-feature.sh 1`} />

<Note title="You need">
  Git, the GitHub CLI, `jq`, Claude Code and Codex. `doctor.sh` checks all of it.
</Note>
